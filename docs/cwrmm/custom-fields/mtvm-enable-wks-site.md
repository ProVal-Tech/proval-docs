## Summary

Enables or disables Memory monitoring for workstations at the Site level. Overrides Company settings, but overridden by Endpoint.

## Dependencies

- [Solution: Memory Threshold Violation Monitoring](/docs/cda6ee21-e70f-45c3-868c-1800d4aa26d7)

## Custom Field Setup Location

**Custom Fields Path:** SETTINGS ➞ Custom Fields

## Details

| Name | Description | Level | Type | Option Type | Options | Help Text | Default Value | Editable |
|---|---|---|---|---|---|---|---|---|
| MTVM_Enable_Wks_Site | Enables or disables Memory monitoring for workstations at the Site level. Overrides Company settings, but overridden by Endpoint. | `Site` | `Dropdown` | `string` | `Enable`, `Disable` | Select Enable to turn on monitoring, Disable to exclude. |  | `Yes` |
