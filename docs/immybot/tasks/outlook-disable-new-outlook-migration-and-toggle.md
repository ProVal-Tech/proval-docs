## Description

This Immy script configures Outlook registry settings for all currently loaded Windows user profiles to control the New Outlook experience.

It sets the following registry values to 1:

NewOutlookMigrationUserSetting — Configures the user's New Outlook migration setting.
HideNewOutlookToggle — Hides the New Outlook toggle in Outlook.
