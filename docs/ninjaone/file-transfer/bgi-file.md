## Overview

The purpose of this file transfer is to place the BGI file or BGI ZIP file at the location below so it can be used by [Automation - Configure BGInfo](/docs/408cc622-de6a-4913-9150-267dcb4685e3).

Both `.zip` and `.bgi` files are supported by the automation.

**Path Location:** `C:\ProgramData\_automation\app\BGInfo`
